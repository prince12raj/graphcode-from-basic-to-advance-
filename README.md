# 📊 Graph Algorithms: From Basic to Advanced

This repository is a complete guide to Graph Data Structures and Algorithms, covering concepts from beginner to advanced level. It is useful for **interviews, competitive programming, and academic learning**.

### 🔹 7. Minimum Spanning Tree (MST)

* Prim’s Algorithm
* Kruskal’s Algorithm

### 🔹 8. Disjoint Set (Union-Find)

### 🔹 9. Advanced Graph Algorithms
